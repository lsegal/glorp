<section class="skill-hero create-hero"><p class="eyebrow">GitHub issue filer</p><h1>One request.<br><em>One complete issue.</em></h1><p class="hero-copy"><code>gh-create</code> turns a quick request into an issue another person or agent can act on, and files it the same way no matter which agent you asked.</p><div class="hero-actions"><a class="button primary" href="#install">Install gh-create</a><a class="button ghost" href="https://github.com/lsegal/glorp/tree/main/.agents/skills/gh-create">Read the skill</a></div></section>

<section class="process-strip create-strip" aria-label="gh-create process"><div><b>01</b><span>Check the repo<br>and its visibility</span></div><div><b>02</b><span>Research, if it<br>helps (optional)</span></div><div><b>03</b><span>Write, label,<br>assign, attach</span></div><div><b>04</b><span>File it, then<br>check how it renders</span></div></section>

<section class="split-section"><div><p class="eyebrow">Same issue, any agent</p><h2>Expanded, but never rewritten away.</h2><p>The agent writes a structured issue: a summary, steps to reproduce or numbered requirements, expected and actual behavior, and acceptance criteria. Your original prompt is quoted word for word at the bottom, so the issue can be reproduced, replayed, and audited.</p><p>It applies every label the repository already has that fits, such as kind, platform, and area, and never invents one. It assigns the issue to you with <code>@me</code> unless you ask for someone else or for nobody.</p></div><div class="github-mock" aria-label="Illustrative GitHub issue card"><div class="mock-top"><span class="gh-mark">◉</span><span>Issues · New</span><span class="mock-dots">•••</span></div><div class="mock-body"><h3>Crash when saving an empty file</h3><p>bug · windows · ui · assigned to you</p><div class="mock-comment"><b>Summary · Steps · Expected · Actual</b><span>Screenshot uploaded and embedded. Original prompt quoted below.</span></div></div></div></section>

<section class="workflow-section quiet-workflow"><p class="eyebrow">The hard parts, written down</p><h2>Media that renders. Secrets that don&rsquo;t.</h2><div class="callout-grid"><article><strong>Media actually attached</strong><p>Screenshots and videos you mention are uploaded with <code>gh issue create --attach</code>, or GitHub&rsquo;s upload endpoint as a fallback, then the filed issue is read back to confirm no local path is left behind.</p></article><article><strong>Private data scrubbed</strong><p>Local paths, names, emails, hostnames, and tokens stay out, even in the quoted prompt. A public issue never mentions a private repository or its code.</p></article><article><strong>Research is optional</strong><p>With the repository at hand it can point to the files involved and link related issues, but it never holds up filing.</p></article></div></section>

<section id="install" class="install-section create-install"><p class="eyebrow">Install separately</p><h2>Give every agent the same issue template.</h2><div class="install-grid"><article><h3>skills.sh</h3><p>Install for your selected agents in one command.</p><pre><code>npx --yes skills add lsegal/glorp@gh-create --global --agent codex --agent claude-code --agent gemini-cli --agent opencode --agent cline --agent universal -y</code></pre></article><article><h3>GitHub CLI</h3><p>Install the bundled skill directly for your agent.</p><pre><code>gh skill install lsegal/glorp gh-create --allow-hidden-dirs --agent codex --agent claude-code --scope user</code></pre></article></div><p class="run-example"><span>Run it</span><code>/gh-create owner/repo the save button crashes on empty files, see ./crash.png</code></p></section>
