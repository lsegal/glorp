<section class="skill-hero discuss-hero"><p class="eyebrow">GitHub discussion responder</p><h1>One thread.<br><em>One useful answer.</em></h1><p class="hero-copy"><code>gh-discuss</code> is the careful counterpart to <code>gh-fix</code>: it researches one unanswered Discussion and replies only when the repository supports a complete, confident answer.</p><div class="hero-actions"><a class="button primary" href="#install">Install gh-discuss</a><a class="button ghost" href="https://github.com/lsegal/glorp/tree/main/.agents/skills/gh-discuss">Read the skill</a></div></section>

<section class="process-strip discuss-strip" aria-label="gh-discuss process"><div><b>01</b><span>Validate the<br>single thread</span></div><div><b>02</b><span>Read the question,<br>not the noise</span></div><div><b>03</b><span>Research only<br>inside the repo</span></div><div><b>04</b><span>Reply once—or<br>leave it alone</span></div></section>

<section class="split-section"><div><p class="eyebrow">A deliberately narrow tool</p><h2>Helpful without making a mess.</h2><p>It does not execute code, change files, open branches, or rummage through unrelated sources. Its only possible write is one top-level answer to one GitHub Discussion.</p><p>Already answered? Not actually a question? The repository cannot settle it? It exits quietly. That restraint is the feature.</p></div><div class="github-mock discussion-mock" aria-label="Illustrative GitHub Discussion card"><div class="mock-top"><span class="gh-mark">◉</span><span>Discussions · Q&amp;A</span><span class="mock-dots">•••</span></div><div class="mock-body"><span class="answer-pill">Answered</span><h3>Can I use this with a Project?</h3><p>Asked in Q&amp;A · 1 reply</p><div class="mock-comment"><b>gh-discuss</b><span>Yes—Projects are accepted as watch targets. Here’s the supported form.</span></div></div></div></section>

<section class="workflow-section quiet-workflow"><p class="eyebrow">The decision gate</p><h2>Confidence first. Comment second.</h2><div class="decision-map"><div class="decision-start"><b>New discussion</b><span>no replies yet</span></div><div class="decision-lines"><span>Is it answerable from the repository?</span><div><b class="yes">yes →</b><b class="no">no ↓</b></div></div><div class="decision-answer"><b>One precise reply</b><span>top-level only</span></div><div class="decision-stop"><b>Leave untouched</b><span>no partial answers</span></div></div><div class="callout-grid"><article><strong>Thread stays small</strong><p>It ignores nested replies and never adds a second top-level comment.</p></article><article><strong>Repository evidence only</strong><p>Answers come from the project’s own files, docs, and GitHub history—not guesswork.</p></article><article><strong>Read-only by design</strong><p>No builds, no commits, no mutations. A warranted answer is the entire outcome.</p></article></div></section>
